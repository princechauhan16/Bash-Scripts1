# Bash Scripts

## Site Connectivity Checker

A simple Bash script that checks whether a website, hostname, or IP address is reachable using the `ping` command.

## Features

- Takes a website or host as input
- Sends one ping request
- Checks the ping result
- Displays a success or failure message

## Requirements

- Linux
- Bash
- ping

## Usage

```bash
chmod +x site-check.sh
./site-check.sh
